# Contributing

This repository is a read-only mirror of `packages/cli` in the Mentio monorepo,
published on every release. Issues are welcome here and are read; pull
requests cannot be merged here because the source lives upstream, so open an
issue with what you would change and we take it from there.

- Documentation: https://docs.mentio.dev
- API reference: https://docs.mentio.dev/api/keywords/create-keyword
- Mentio: https://mentio.dev
